# E-Commerce Microservices

## Description
Application e-commerce basée sur une architecture microservices avec Spring Cloud et Angular.

## Microservices
- Customer Service : gestion des clients.
- Inventory Service : gestion des produits.
- Billing Service : gestion de la facturation.
- Discovery Service : découverte des services avec Eureka.
- Config Service : centralisation de la configuration.
- Gateway Service : point d'entrée des requêtes.

## Frontend
Le dossier `ecom-client-ang` contient l'application Angular.

## Technologies
Java, Spring Boot, Spring Cloud, Eureka, Spring Cloud Gateway,
Spring Cloud Config, OpenFeign, Angular et Maven.
